# LaunchPad v1.0.0 — 全新起点

LaunchPad 版本线重新更迭，从这里（v1.0.0）重新开始计数。此版本汇集了此前迭代沉淀的全部能力：工作空间启动器 + 系统效率工具 + AI 工作桌宠。

## 工作空间与启动

- 工作空间管理：一键批量启动/关闭一组软件。
- 软件库：自动扫描、Everything 快速搜索、EXE 图标识别。
- BAT/CMD 脚本库与自动化，启动后自动执行。

## 系统效率

- 系统托盘、开机启动、关闭窗口驻留托盘。
- 进程管理控制台：按名称 / PID / 端口搜索并结束进程。
- 性能监控：CPU / 内存 / 磁盘 / 网络实时面板与进程排行。
- 全局快捷键：唤起主窗口与快速启动工作空间。
- 简体中文、English、日本語 三语言界面。

## AI 工作桌宠

- 独立透明桌宠：多动画状态、漫游、拖拽与右键菜单。
- AI 对话：流式输出（打字机效果）、多会话、长期记忆。
- 模型衣橱：导入 Codex 兼容精灵图，或让 AI 直接设计新桌宠（SVG 参数化）。
- Function Calling：工作空间 / 进程 / 浏览器 / Shell 操作，支持完全权限与审计日志。
- 对话内容完整支持 Markdown 渲染。

## 更新与体验

- 自动更新：检测、下载、重启安装，支持后台静默与全自动。
- 数据导入导出、存储路径迁移、诊断与崩溃日志。
- 更新日志弹窗从本版本开始展示历史。

## 系统要求

- Windows 10 / Windows 11
- x64 处理器
