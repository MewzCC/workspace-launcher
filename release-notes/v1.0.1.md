# LaunchPad v1.0.1 — 多桌宠与互动记忆

这个版本让桌宠从"一只"变成"一群"：支持多桌宠共存、桌宠之间的社交互动，并内置三款官方桌宠。

## 新增

- 多桌宠支持：可同时养多只桌宠，每只拥有独立的会话与记忆。
- 互动记忆系统：桌宠之间会互相认识、记住彼此的互动经历。
- 桌宠自动互动：桌宠会主动打招呼、闲聊与回应。
- 内置三款官方桌宠：feibi、blue-whale-maid（蓝鲸女仆）、klee-spark-knight（火花骑士）。
- 宠物打包工具链：一键打包自定义桌宠模型。

## 优化

- 重构模型存储路径逻辑，多模型管理更清晰。
- 更新三语言文案与教程文档。

## 下载

- `LaunchPad-Setup-1.0.1-x64.exe`：推荐安装版，支持自动更新。
- `LaunchPad-Portable-1.0.1-x64.exe`：便携版，更新时需手动下载新版本。

## 系统要求

- Windows 10 / Windows 11
- x64 处理器
