# LaunchPad v1.0.2 — 桌宠学习助手 📚

这个版本让你的桌宠成为学习搭子 🎓：基于间隔重复算法的记忆卡片，桌宠会定时陪你复习、巩固知识。

## ✨ 新增

- 🧠 **学习卡片系统**：添加知识点卡片，桌宠按记忆规律安排复习（稳定性 / 可提取性建模的间隔重复算法）。
- ⏰ **陪伴式复习**：桌宠定时弹出卡片提醒复习（companion 模式），间隔可在 5 秒 ~ 10 分钟自由调节。
- ⌨️ **快捷键快速记**：全局快捷键一键呼出快速添加面板，灵感来了立刻记下；支持快捷键冲突校验。
- 🖥️ **学习面板**：桌宠工作台新增学习管理面板，卡片增删、复习进度一目了然。
- 💬 **气泡复习**：复习内容通过桌宠气泡展示，边看边学。

## 🔧 优化

- 🗄️ 新增学习数据独立存储（petStudyDao），与聊天记忆互不干扰。
- ✅ 新增 `npm run test:pet-study` 学习系统验证脚本。
- 🎨 学习相关界面完整适配明暗主题与三语言。

## 📥 下载

- 🚀 `LaunchPad-Setup-1.0.2-x64.exe`：推荐安装版，支持自动更新。
- 🎒 `LaunchPad-Portable-1.0.2-x64.exe`：便携版，更新时需手动下载新版本。

## 💻 系统要求

- 🪟 Windows 10 / Windows 11
- ⚙️ x64 处理器
