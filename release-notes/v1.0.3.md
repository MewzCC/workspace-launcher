# LaunchPad v1.0.3 — 拖拽动画与词库搜索 🎯

这个版本让桌宠动起来更生动 🐾：拖拽时有专属动画反馈，学习词库支持搜索，多页面全面适配小屏。

## ✨ 新增

- 🐾 **桌宠拖拽动画**：拖起、放下都有动画反馈，互动感拉满。
- 🔍 **词库搜索**：学习卡片词库支持关键词搜索，快速定位知识点。

## 🔧 优化

- 📱 多页面响应式布局优化，窄窗口下不再错位。
- 💅 桌宠相关样式细节打磨。

## 📥 下载

- 🚀 `LaunchPad-Setup-1.0.3-x64.exe`：推荐安装版，支持自动更新。
- 🎒 `LaunchPad-Portable-1.0.3-x64.exe`：便携版，更新时需手动下载新版本。

## 💻 系统要求

- 🪟 Windows 10 / Windows 11
- ⚙️ x64 处理器
