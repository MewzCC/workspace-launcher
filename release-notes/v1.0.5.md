# LaunchPad v1.0.5 — 桌宠学习进阶 🎓

这个版本让学习更聪明高效 ✨：掌握的词条自动毕业 🎉，模式切换与快捷添加更顺手 ⌨️

## ✨ 新增

- 🎓 **已掌握状态**：点击“会”即可让词条永久毕业，不再进入复习队列，专注未掌握内容
- 🔄 **模式切换快捷键**：新增 `Ctrl+Alt+M` 一键切换学习模式（陪伴 / 学习 / 摸鱼学习）
- 🪄 **快捷操作智能切换**：学习模式下右键菜单自动变为“认识当前词条”，其他模式为快速添加

## 🔧 优化

- ✅ **快捷键冲突检测升级**：学习快捷键与模式切换快捷键互斥检测，避免占用
- 🪟 **快速添加窗口可切换**：重复触发快捷键可开关窗口，操作更流畅
- 📊 **统计口径优化**：已掌握词条不计入待复习，已掌握计入复习总数
- 🎨 **学习面板细节**：新增已掌握徽章样式，操作列自适应优化
- 🛡️ **校验加固**：IPC 校验与学习数据验证更严谨

## 📥 下载

- 🚀 `LaunchPad-Setup-1.0.5-x64.exe`：推荐安装版，支持自动更新
- 🎒 `LaunchPad-Portable-1.0.5-x64.exe`：便携版，更新时需手动下载新版本

## 💻 系统要求

- 🪟 Windows 10 / Windows 11
- ⚙️ x64 处理器
