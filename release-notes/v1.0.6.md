# LaunchPad v1.0.6 — 托盘中心与桌宠自由缩放 🚀

这个版本让托盘成为真正的控制中心 🧰：不打开主窗口也能检查更新、开关桌宠、直达设置。

## ✨ 新增

- 🧰 **托盘控制中心**：右键菜单新增「检查更新」「启动桌宠」开关、「桌宠中心」「设置」直达入口。
- 🔍 **托盘检查更新**：一键检查并弹窗反馈结果（已是最新 / 发现新版 / 失败原因），有更新时可直接跳转。
- 📡 **托盘实时状态**：菜单动态显示「正在检查…」「查看更新 v1.0.x」「更新已就绪」，窗口显示/隐藏状态自动同步。
- 🎚️ **桌宠大小自由调**：桌宠缩放上限从 135% 提升到 **500%**，想要多大有多大。

## 🔧 优化

- 🐾 桌宠全局开关重构：关闭后重新开启自动恢复上次模型，多实例同步更可靠。
- 🪟 透明度统一：聊天窗、气泡、快速添加窗口跟随桌宠透明度设置。
- 🖥️ 小屏幕保护：桌宠位置边界计算修复，超小屏不再出现越界负坐标。
- 🔕 手动检查更新不受「跳过此版本」影响，且不再误触发自动更新弹窗。

## 📥 下载

- 🚀 `LaunchPad-Setup-1.0.6-x64.exe`：推荐安装版，支持自动更新
- 🎒 `LaunchPad-Portable-1.0.6-x64.exe`：便携版，更新时需手动下载新版本

## 💻 系统要求

- 🪟 Windows 10 / Windows 11
- ⚙️ x64 处理器
