# LaunchPad v1.0.7 — Live2D 桌宠与多模态识图 🎭👁️

这个版本让桌宠真正“看得见、动起来” 💫：新增 Live2D 模型支持与多模态识图，并补上按 API Key 拉取模型的能力。

## ✨ 新增

- 🎭 **Live2D 桌宠**：支持导入 Live2D 模型包，自动识别、独立资源隔离，并可在模型衣橱中预览与切换。
- 🕺 **动作与表情**：动态读取 Live2D 模型的 motions / expressions 并直接播放，预览失败也可回退启用已加载模型。
- 👁️ **多模态识图**：桌宠中心与桌面浮窗都支持选择、粘贴、拖入图片，还能一键截取屏幕后提问。
- 🧪 **模型能力检测**：发送文本与测试图，明确提示当前模型是否支持识图；连接失败与不支持图片会分别说明。
- 🗂️ **模型选择**：按当前 API Key 拉取可用模型列表，先选模型再保存设置，自定义厂商同样适用。
- 🎨 **素材拖放导入**：支持拖放桌宠素材进行预览与导入，并扩展了自定义桌宠生成技能。

## 🔧 优化

- ⚡ **性能提升**：缓存模型校验结果，桌宠移动时不再重复读取资源。
- 🫥 **启动更平滑**：配置加载期间保持透明，避免闪现内置小人。
- 📦 **导入更稳**：热更新时保留导入预览会话，兼容 Windows 目录重命名受限的情况。
- 🧭 **工作台体验**：优化闲聊控制台布局、分页表格与导入卡片。
- 🧹 **架构精简**：移除不必要的逻辑，维护更轻量。

## 🐛 修复

- 🖱️ 恢复右键菜单关闭与学习轮播。
- 🧲 修复桌宠拖拽占位与开关状态。
- 🚪 修复桌宠改造后主窗口无法启动及启动期 IPC 竞态。
- 🎞️ 修复 Live2D 动作预览失败后无法启用已加载模型的问题。

## 📥 下载

- 🚀 `LaunchPad-Setup-1.0.7-x64.exe`：推荐安装版，支持自动更新
- 🎒 `LaunchPad-Portable-1.0.7-x64.exe`：便携版，更新时需手动下载新版本

## 💻 系统要求

- 🪟 Windows 10 / Windows 11
- ⚙️ x64 处理器
