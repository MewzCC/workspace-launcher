# 🛰️ LaunchPad v1.2.0 — 系统托盘与开机启动

LaunchPad 现在可以真正作为常驻的一键启动中心运行。关闭窗口后继续驻留系统托盘，登录 Windows 时自动启动，还可在启动工作空间前结束已有软件进程并重新拉起。

## ✨ 本次更新

- 🛰️ 新增系统托盘图标与右键菜单
- 🚀 可直接从托盘一键启动任意工作空间
- 👆 单击托盘图标即可显示或隐藏主窗口
- 🪟 关闭主窗口时默认收起到托盘，不再退出应用
- ⚡ 支持 Windows 开机自动启动
- 🌙 支持开机后静默驻留托盘，不打扰桌面
- 🔒 新增单实例保护，重复启动时自动唤起已有窗口
- 🔄 新增“启动前结束已有进程”开关
- 🎯 结束进程时按完整 EXE 路径精确匹配，避免误杀同名软件
- 🛡️ 自动保护 LaunchPad 自身进程，并在权限不足时继续安全启动流程
- ⚙️ 设置页新增完整“系统与启动”控制面板

## 📥 下载选择

- **LaunchPad-Setup-1.2.0-x64.exe**：Windows 安装版，可选择安装目录，并创建桌面与开始菜单快捷方式。
- **LaunchPad-Portable-1.2.0-x64.exe**：免安装便携版，下载后双击即可使用。

## 💻 系统要求

- Windows 10 / Windows 11
- x64 处理器
