# LaunchPad v1.4.1 — 自动更新与数据路径升级

LaunchPad v1.4.1 完善了工程化发布能力，并让用户数据位置和应用版本管理更加清晰可靠。

## 本次更新

- 🔄 **自动更新**：安装版自动检查 GitHub Releases，支持手动下载、进度展示和重启安装。
- 📝 **更新日志预览**：检测到新版本后，在设置页直接查看 Release Notes。
- 📁 **用户数据路径**：默认在安装目录创建 `LaunchPadData`，设置页展示数据库和数据目录位置。
- 🛡️ **权限回退**：安装目录不可写时自动使用用户数据目录，并明确提示实际路径。
- 🧩 **动态版本**：应用界面版本从 `package.json` 自动读取，只需修改一个版本源。
- 🔧 **原生依赖修复**：安装依赖时自动为当前 Electron 重建 better-sqlite3。

## 下载

- `LaunchPad-Setup-1.4.1-x64.exe`：推荐安装版，支持自动更新。
- `LaunchPad-Portable-1.4.1-x64.exe`：便携版，更新时需手动下载新版本。

## 系统要求

- Windows 10 / Windows 11
- x64 处理器
