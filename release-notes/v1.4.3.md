# LaunchPad v1.4.3 — 安装体验优化

LaunchPad v1.4.3 优化了安装向导体验。

## 本次更新

- 👤 **默认仅为我安装**：安装时不再询问“为哪位用户安装”，直接按当前用户安装。
- 🚫 **无默认启动**：安装完成后不会自动运行 LaunchPad（首次安装与更新均如此）。
- 📄 **更新无完成向导**：更新时安装进度结束后直接结束，不显示完成页。
- 🧭 **首次安装保留向导**：新用户仍可自由选择安装目录。

## 下载

- `LaunchPad-Setup-1.4.3-x64.exe`：推荐安装版，支持自动更新。
- `LaunchPad-Portable-1.4.3-x64.exe`：便携版，更新时需手动下载新版本。

## 系统要求

- Windows 10 / Windows 11
- x64 处理器
