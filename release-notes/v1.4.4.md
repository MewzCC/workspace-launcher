# LaunchPad v1.4.4 — 更新日志与回滚

LaunchPad v1.4.4 新增更新日志弹窗，支持查看全部版本记录并回滚旧版本。

## 本次更新

- 📜 **更新日志弹窗**：设置页新增「更新日志」入口，查看全部版本发布历史。
- 🗂️ **版本卡片**：每个版本一张卡片，展示更新内容与发布日期，当前版本带标记。
- ⬇️ **下载旧版回滚**：每个版本右上角可下载对应旧安装包，随时回滚。
- 🖥️ **开发模式检查更新**：开发环境也能手动检查更新并预览更新日志。
- 📝 **Markdown 渲染**：更新内容支持 Markdown 展示，自动过滤“下载/系统要求”等无用章节。

## 下载

- `LaunchPad-Setup-1.4.4-x64.exe`：推荐安装版，支持自动更新。
- `LaunchPad-Portable-1.4.4-x64.exe`：便携版，更新时需手动下载新版本。

## 系统要求

- Windows 10 / Windows 11
- x64 处理器
