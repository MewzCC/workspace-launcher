# LaunchPad v1.4.5 — 诊断能力与设置体验优化

LaunchPad v1.4.5 新增崩溃诊断能力，并重新组织设置页布局。

## 本次更新

- 🩺 **诊断与崩溃日志**：应用异常自动写入本地 `.txt` 可读日志，支持打开日志目录。
- 📋 **一键复制诊断报告**：包含版本、系统、更新错误码与最近错误，粘贴到 Issue 即可快速反馈。
- 🗂️ **设置页分类切换**：通用 / 更新 / 数据 / 诊断四个标签页，不再长页滚动，明暗主题自动适配。
- 🤖 **GitHub Actions 自动发布**：推送 tag 自动构建安装包、便携版并发布 Release。

## 下载

- `LaunchPad-Setup-1.4.5-x64.exe`：推荐安装版，支持自动更新。
- `LaunchPad-Portable-1.4.5-x64.exe`：便携版，更新时需手动下载新版本。

## 系统要求

- Windows 10 / Windows 11
- x64 处理器
