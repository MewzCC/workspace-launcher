# LaunchPad v1.5.1 — 桌宠聊天与记忆

这个版本让桌宠拥有了聊天、记忆与更完整的陪伴体验。

## 新增

- 桌宠聊天输入与对话气泡：可以直接和桌宠对话，回复会以气泡形式展示。
- 桌宠漫游设置与右键菜单：回家、隐藏、打开 LaunchPad 等操作一键直达。
- AI 会话管理：支持多会话创建与切换，历史记录持久化保存。
- AI 记忆管理：桌宠会记住主人的偏好与重要信息，跨会话持续生效。

## 体验优化

- 数据与桌宠模型目录支持自动迁移，升级后原有模型与数据完好保留。
- 发布说明统一整理到 `release-notes/` 目录。
- README 新增英文与日文版本。

## 下载

- `LaunchPad-Setup-1.5.1-x64.exe`：推荐安装版，支持自动更新。
- `LaunchPad-Portable-1.5.1-x64.exe`：便携版，更新时需手动下载新版本。

## 系统要求

- Windows 10 / Windows 11
- x64 处理器
