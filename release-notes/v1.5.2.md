# LaunchPad v1.5.2 — AI 完全权限与流式对话

这个版本让桌宠真正成为工作助手：支持流式回答、Function Calling 工具调用、完全权限（Shell 接管），并大幅优化对话体验与内存占用。

## 新增

- AI 完全权限（Shell 接管）：桌宠可结束进程、执行 PowerShell 命令；开启时需确认风险，所有操作写入审计日志。
- 浏览器工具：AI 可自动打开网页或搜索信息，无需用户手动操作。
- AI 流式输出：对话回复逐字呈现，桌宠气泡同步打字机效果。
- Markdown 渲染升级：基于开源组件，聊天记录、气泡、备忘录均支持完整 Markdown 语法（标题、列表、表格、代码等）。
- AI 了解产品能力：项目发布历史注入 AI 上下文，回答产品问题更准确。

## 体验优化

- 聊天记录默认滚动到最新消息，进入聊天不再从头开始。
- 对话框行为回归单一气泡：关闭聊天即消失，不再出现多个对话框。
- 桌宠内存优化：关闭桌宠或聊天窗口后立即回收渲染进程，不再常驻占用。
- 修复切换桌宠页面黑屏的问题。
- 修复工作空间查询导致的 AI 对话失败问题。

## 技术改进

- IPC 架构重构：声明式通道注册表 + 参数契约校验，多模块路由分层管理。
- AI 请求支持 SSE 流式解析，兼容 Responses API 与 Chat Completions。

## 下载

- `LaunchPad-Setup-1.5.2-x64.exe`：推荐安装版，支持自动更新。
- `LaunchPad-Portable-1.5.2-x64.exe`：便携版，更新时需手动下载新版本。

## 系统要求

- Windows 10 / Windows 11
- x64 处理器
